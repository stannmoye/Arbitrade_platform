## Status definitions

- **VERIFIED** — the narrowly stated requirement has executable test or exact-head workflow evidence. This does not imply hosted production acceptance.
- **IMPLEMENTED BUT NOT VERIFIED** — relevant code exists, but a required behavior, integration, browser run, runtime authorization, or exact-head evidence remains incomplete.
- **MISSING** — no current supported implementation/evidence satisfies the stated requirement.
- **BLOCKED** — completion depends on an external authoritative lifecycle, infrastructure, or owner action that is absent or intentionally out of scope.

A row can be VERIFIED for its bounded automated scope while a separate row remains open for product/runtime acceptance. CI success is not a substitute for browser, accessibility, provider, or owner evidence.
