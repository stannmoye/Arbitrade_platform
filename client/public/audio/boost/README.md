# Boost sound assets

These five short preview files are bundled from Mixkit's free Sci-Fi sound-effects collection, which states that the sounds are free to download under the Mixkit License:

- `mixkit-1030.mp3`
- `mixkit-1093.mp3` (selected default active-boost loop)
- `mixkit-164.mp3`
- `mixkit-1679.mp3`
- `mixkit-1681.mp3`

Source: https://mixkit.co/free-sound-effects/sci-fi/
License: https://mixkit.co/license/

The application uses the selected default file as a looping active-boost ambience and stops playback as soon as the boost leaves the active state or the customer leaves the page.
